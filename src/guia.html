01

Estructura del script

Las instrucciones de cabecera y de cierre. Definen qué se ve en pantalla, en qué codificación se interpreta el texto y cómo termina el script sin dejar la ventana colgada.

12sintaxis
@echo off base

Apaga el eco: la consola deja de imprimir cada línea del script y solo muestra lo que imprimes con echo. La @ evita que esa misma línea se muestre. Va siempre en la primera línea útil.

Dónde verlo los 26 .bat

chcp 65001 >nul base

Cambia la página de códigos de la consola a UTF-8 para que las tildes y la ñ se vean bien en lugar de «Â¡» o «Ã©». El >nul oculta el mensaje «Código de página activo: 65001».

Dónde verlo angela.bat, CRISTIAN.bat, ROYNER.bat

! No basta con escribirlo: guarda el archivo en UTF-8. Programas.bat muestra «Â¡Escaneo» porque su texto y su codificación no coinciden.

title Centro de Utilidades base

Cambia el título de la ventana de consola. Es cosmético, pero ayuda a identificar el script cuando hay varias ventanas abiertas.

Dónde verlo CAMILO.bat, JORGE.bat, EDWIN2.bat

color 0A base

Cambia los colores de la consola: el primer dígito es el fondo y el segundo el texto, en hexadecimal (0 negro, 1 azul, A verde claro, F blanco). 0A = fondo negro con texto verde tipo Matrix; 1F = fondo azul y texto blanco. Sin argumentos, color restablece el esquema por defecto.

Dónde verlo CAMILO.bat (0A), DANIEL.bat (1F)

cls base

Borra la pantalla. Se usa al abrir cada pantalla del menú para que no se acumulen las opciones anteriores.

Dónde verlo JAIRO.bat, JORGE.bat

pause base

Muestra «Presione una tecla para continuar...» y espera a que el usuario pulse algo. Sirve para que la ventana no se cierre antes de que se lea el resultado.

Dónde verlo casi todos

pause >nul base

Igual que pause pero sin el mensaje, porque la salida se manda al dispositivo nul, la «papelera» del sistema.

Dónde verlo CRISTIAN.bat, JULIAN.bat

! El dispositivo correcto es nul, nunca null: pause > null crea un archivo llamado «null» en la carpeta y no silencia nada.

timeout /t 3 >nul base

Espera 3 segundos sin cuenta regresiva y sin pedir tecla. Con /nobreak la espera no se puede cancelar pulsando una tecla. Es la pausa correcta, mejor que el truco ping 127.0.0.1 -n 4 >nul.

Dónde verlo angela.bat, JORGE.bat, ROYNER.bat

@pause · @echo off base

La @ antepuesta a cualquier comando impide que ese comando se imprima aunque el eco esté activo. Es costumbre de los scripts antiguos.

Dónde verlo EjemplosBatch.bat

exit base

Cierra la ventana de consola y termina el proceso. Es lo adecuado en scripts que se lanzan con doble clic.

Dónde verlo varios

exit /b avanzado

Termina el script o la subrutina pero SIN cerrar la ventana: devuelve el control a quien lo llamó. Es lo correcto en menús y en subrutinas invocadas con call.

Dónde verlo CRISTIAN.bat, JAIRO.bat, JULIAN.bat

exit /b 0 · exit /b 1 avanzado

Igual que exit /b, pero además devuelve un código de resultado explícito (0 = éxito, 1 = fallo). El llamador lo consulta con if errorlevel.

Dónde verlo JULIAN.bat (:Confirmar)

02

Comentarios

Tres formas de escribir texto que el intérprete ignora. No son intercambiables: una falla dentro de bloques y detrás de tuberías.

3sintaxis
rem esto es un comentario base

REM = REMark: el resto de la línea se ignora por completo. Es el comentario seguro porque funciona en cualquier posición, incluso dentro de bloques ( ) y detrás de tuberías.

Dónde verlo DANIEL.bat, JEINER.bat, JULIAN.bat

@rem comentario base

Igual que rem, pero la propia línea del comentario tampoco se muestra si el eco estuviera activo.

Dónde verlo EjemplosBatch.bat

:: comentario base

Truco habitual: crea una etiqueta vacía y el segundo «:» la deja inalcanzable, así que el intérprete la ignora. Más rápido de escribir que rem.

Dónde verlo EDWIN.bat, JORGE.bat, broma.bat

! No funciona dentro de bloques ( ... ) ni detrás de un pipe: ahí rompe el script. En esos casos usa rem.

03

Salida por pantalla — ECHO

echo escribe texto y expande variables. Sus variantes controlan líneas en blanco, porcentajes y caracteres que el intérprete interpretaría como sintaxis.

6sintaxis
echo Hola usuario %USERNAME% base

Imprime el texto tal cual, expandiendo antes las variables entre porcentajes: %USERNAME% se sustituye por el usuario de Windows.

Dónde verlo JAIRO.bat, EjemplosBatch.bat

echo. base

Imprime una línea en blanco; el punto forma parte del comando. Se usa para dar aire entre las secciones de un menú.

Dónde verlo JORGE.bat, JULIAN.bat, ROYNER.bat

! echo sin nada imprime el estado del eco (on/off); echo. siempre imprime una línea vacía.

echo Uso de CPU: !CPUL!%% base

El signo de porcentaje literal se escribe %%; un % solo intenta abrir una variable y rompe la línea.

Dónde verlo WinSysToolkit-ELKIN.bat

echo IP_LOCAL ^| IP_REMOTA avanzado

El circunflejo ^ escapa el carácter siguiente: aquí una barra vertical que NO debe funcionar como tubería. Lo mismo aplica a ^( y ^) para paréntesis literales.

Dónde verlo JORGE.bat, JAIRO.bat

echo hola -^> listo avanzado

El ^ también escapa la flecha -> para que no se confunda con una redirección.

Dónde verlo JAIRO.bat

echo ESTE TEXTO >> hola1.txt base

echo es la vía normal para escribir o añadir líneas a un archivo, combinado con > o >>. El taller lo usa como forma de «adicionar contenido».

Dónde verlo IRAIDA.bat, EDWIN2.bat

04

Variables — SET

set crea, lee, borra y calcula variables. Aquí está también la lectura del teclado y la sustitución de texto, que es la base de casi todos los menús.

13sintaxis
set nombre=Juan base

Crea la variable nombre con el valor Juan. No debe haber espacios alrededor del signo igual.

Dónde verlo varios

! set nombre = Juan crea una variable llamada «nombre » (con espacio final) y con valor « Juan»; luego %nombre% no existe. ERIKA.bat tiene exactamente ese bug.

set "reporte=%~dp0Reporte.txt" base

Forma recomendada: entrecomillar toda la asignación permite valores con espacios y caracteres especiales, sin cortes en el primer espacio ni espacios parásitos.

Dónde verlo CRISTIAN.bat, DANIEL.bat, JULIAN.bat

set PASS=admin123 peligro

Variable con una clave fija que después se compara en un if para simular un inicio de sesión.

Dónde verlo IRAIDA.bat

! No es protección real: cualquiera que abra el .bat en un editor ve la clave. En batch todo es texto plano.

set /p opcion=Seleccione una opcion: base

Lee lo que teclea el usuario y lo guarda en opcion, mostrando el prompt sin salto de línea. Es el corazón de todos los menús del proyecto.

Dónde verlo CAMILO.bat, JORGE.bat, YORMAN.bat

set /p "op=Elige una opcion: " base

Variante segura: entrecomillar el prompt completo evita que espacios accidentales contaminen la variable.

Dónde verlo broma.bat

set /p OLDWP=<"estado\fondo_original.txt" avanzado

Lee la PRIMERA LÍNEA de un archivo y la guarda en la variable, en lugar de leer del teclado: el < es «entrada desde archivo».

Dónde verlo counter.bat

set /a contador=contador+1 base

El modificador /a convierte set en calculadora: evalúa la parte derecha como expresión aritmética y permite nombrar la variable sin %...% dentro de su propia fórmula. Es el contador típico de los bucles for.

Dónde verlo EjemplosBatch.bat, DANIEL.bat

set /a media=(%num1% + %num2%) / 2 avanzado

Con /a se dispone de paréntesis, + - * / y % (módulo), operadores de bits (& | ^ << >> ~) y las asignaciones += -= *= /=.

Dónde verlo EjemplosBatch.bat

set /a "x = x + 1" avanzado

Las comillas alrededor de la expresión son opcionales: /a las ignora.

Dónde verlo EjemplosBatch.bat

! Dentro de un bloque ( ) o de un for, la variable no se vuelve a leer con %x% hasta la línea siguiente del bloque: para eso existe la expansión retardada.

set base

Sin argumentos imprime TODAS las variables del entorno activo. Útil para depurar.

Dónde verlo DANIEL.bat: set > variables.txt

set raiz base

Con solo un nombre o prefijo, set imprime las variables que empiezan por ese texto.

Dónde verlo —

set "raiz=" base

Asignar un valor vacío BORRA la variable. Se hace antes de un set /p para no arrastrar la respuesta anterior si el usuario pulsa Enter sin escribir.

Dónde verlo CRISTIAN.bat, JAIRO.bat, JULIAN.bat

set "raiz=%raiz:"=%" avanzado

Sustitución de texto dentro de una variable con la forma %var:busca=reemplaza%. Aquí busca todas las comillas y las reemplaza por nada, para quitar las que Windows añade al arrastrar una carpeta sobre la ventana.

Dónde verlo JAIRO.bat

05

Entorno y expansión retardada

Las variables que Windows ya trae, el problema de leer variables dentro de un bloque y las dos formas de resolverlo: setlocal enabledelayedexpansion y if errorlevel.

9sintaxis
echo %USERNAME% %COMPUTERNAME% %DATE% %TIME% base

Variables predefinidas por Windows: usuario, nombre del equipo, fecha y hora actuales.

Dónde verlo JAIRO.bat, EjemplosBatch.bat

%CD% %HOMEPATH% %TEMP% %USERPROFILE% base

Carpeta actual, ruta del perfil, carpeta temporal y perfil completo. Otras muy usadas: %SYSTEMROOT%, %ALLUSERSPROFILE%, %NUMBER_OF_PROCESSORS% y %PROCESSOR_ARCHITECTURE%.

Dónde verlo EjemplosBatch.bat, EDWIN2.bat

%RANDOM% base

Número aleatorio entre 0 y 32767; se usa para nombres únicos y ejercicios de azar.

Dónde verlo EjemplosBatch.bat, taller

setlocal enabledelayedexpansion avanzado

Activa la expansión retardada: desde aquí las variables se pueden leer con !var! y reflejan los cambios hechos dentro del mismo bloque o del for. Casi todos los scripts serios lo abren y lo cierran con endlocal.

Dónde verlo broma.bat, DANIEL.bat, JAIRO.bat, JULIAN.bat

echo !BAR! avanzado

Lectura con expansión retardada: !var! devuelve el valor ACTUAL. Con %var% se obtendría el valor que la variable tenía al entrar al bloque.

Dónde verlo EDWIN2.bat (barra de carga)

endlocal avanzado

Cierra el ámbito abierto por setlocal y descarta las variables creadas dentro, devolviendo el entorno a como estaba.

Dónde verlo EDWIN.bat, JULIAN.bat

%errorlevel% · !errorlevel! avanzado

Código de resultado del último comando: 0 = todo bien, cualquier otro número = error. Dentro de un bloque la forma %errorlevel% se evalúa tarde; por eso se prefiere !errorlevel! o la forma if errorlevel N.

Dónde verlo EDWIN2.bat, YEISON.bat

if errorlevel 1 ( ... ) else ( ... ) avanzado

Azúcar del intérprete que significa «errorlevel MAYOR O IGUAL que 1». No depende de la expansión, así que funciona igual dentro de bloques.

Dónde verlo YEISON.bat, JULIAN.bat

for /f ... do set CPUL=%%A → echo !CPUL!%% avanzado

Patrón clásico: un for /f captura la salida de un comando en una variable y después se imprime con expansión retardada para que no salga vacía.

Dónde verlo WinSysToolkit-ELKIN.bat

06

Argumentos y modificadores

Cómo llegan los datos al script desde la línea de comandos o desde un archivo arrastrado sobre el icono, y cómo extraer partes de una ruta.

9sintaxis
echo %0 %1 %2 %3 base

Al ejecutar script.bat Pedro 20: %0 es el nombre del script, %1 es Pedro y %2 es 20. Los argumentos llegan hasta %9.

Dónde verlo EjemplosBatch.bat

%* base

Contiene TODOS los argumentos a la vez; combinado con un for, se recorren uno a uno.

Dónde verlo for %%n in (%*) do @echo %%n

shift avanzado

Desplaza los argumentos una posición: %2 pasa a ser %1, %3 a %2, etc. Sirve para procesar una lista mientras queden elementos.

Dónde verlo EjemplosBatch.bat

shift /1 · shift /2 avanzado

Descartan a partir del argumento indicado: /1 elimina el primero, /2 elimina el segundo.

Dónde verlo EjemplosBatch.bat

%~f1 %~d1 %~p1 %~n1 %~x1 avanzado

Modificadores que extraen partes del argumento SIN las comillas: ruta completa, unidad, ruta, nombre y extensión.

Dónde verlo EjemplosBatch.bat (programa 6)

%~s1 %~a1 %~t1 %~z1 avanzado

Ruta corta 8.3, atributos del archivo, fecha y hora de modificación, y tamaño en bytes.

Dónde verlo EjemplosBatch.bat

cd /d "%~dp0" base

%~dp0 es la carpeta donde vive el .bat (unidad + ruta, sin comillas) y cd /d cambia también de unidad. Así las rutas relativas funcionan aunque el script se lance desde otra carpeta.

Dónde verlo broma.bat, snapshot.bat, JULIAN.bat

powershell -File "%~dp0comparar.ps1" -Antes "%~1" -Despues "%~2" avanzado

Patrón puente: el .bat recibe los argumentos (por ejemplo dos archivos arrastrados sobre el icono) y se los pasa a un script de PowerShell.

Dónde verlo comparar.bat

if "%1"=="/?" goto AYUDA avanzado

Convención de Windows: si el usuario invoca el script con /? se debe mostrar la ayuda. También se usa if not "%~1"=="hola" echo hola.

Dónde verlo EjemplosBatch.bat

07

Condicionales — IF

Comparar cadenas, números, archivos y códigos de error. Es la sección donde se concentran los errores de sintaxis más comunes del proyecto.

10sintaxis
if "%opcion%"=="1" ( echo Has elegido la opcion 1 pause ) base

Comparación de CADENAS dentro de un bloque: los paréntesis agrupan varias instrucciones bajo una sola condición, y se indentan para leerse. Entrecomilla siempre las dos partes: cuesta nada y evita el fallo más frecuente de batch.

Dónde verlo CAMILO.bat, JAIRO.bat, ROYNER.bat

if exist "%~dp0datos.txt" ( type "%~dp0datos.txt" ) else ( echo Falta el archivo de datos. pause ) base

if ... else: el paréntesis de cierre, la palabra else y el de apertura van en la MISMA línea («) else (») con espacios; así se elige entre dos bloques completos, cada uno con sus propias instrucciones.

Dónde verlo DANIEL.bat, EDWIN2.bat, snapshot.bat

if "%opcion%"=="1" ( goto opcion1 ) else if "%opcion%"=="2" ( goto opcion2 ) else ( echo Opcion invalida goto menu ) avanzado

Cadena de alternativas sin anidar bloques: cada «) else if (...)» añade una condición nueva y el último «) else (» es el caso por defecto. Es el equivalente batch de un switch.

Dónde verlo DANIEL.bat, JEINER.bat, YORMAN.bat

if /i "%respuesta%"=="S" ( echo Actualizando el sistema... goto actualizar ) base

El modificador /i compara sin distinguir mayúsculas: s, S y sO valen lo mismo. Indispensable en las preguntas de S/N.

Dónde verlo CRISTIAN.bat, ROYNER.bat, JULIAN.bat

if not "%CLAVE%"=="%PASS%" ( echo Clave incorrecta goto menu ) base

not niega la condición y deja el bloque para el caso contrario; con él se construye el login de IRAIDA.bat.

Dónde verlo IRAIDA.bat

if %edad% GEQ 18 ( echo MAYOR DE EDAD ) else ( echo MENOR DE EDAD ) base

Comparaciones numéricas: EQU igual, NEQ distinto, LSS menor, LEQ menor o igual, GTR mayor, GEQ mayor o igual. Solo para números: para texto se usa ==.

Dónde verlo EjemplosBatch.bat

if not exist "%~dp0Reportes\" ( mkdir "%~dp0Reportes" echo Carpeta creada. ) else ( echo La carpeta ya existe. ) base

La barra invertida antes de la comilla de cierre hace que if exist compruebe una CARPETA y no un archivo; con if not exist se crea solo si falta, el patrón de las carpetas de salida.

Dónde verlo WinSysToolkit-ELKIN.bat, DANIEL.bat, JULIAN.bat

net session >nul 2>&1 if errorlevel 1 ( echo Necesitas permisos de administrador. pause exit /b 1 ) avanzado

if errorlevel N significa «errorlevel mayor o igual que N»: detecta cualquier error sin depender de la expansión y por eso es la forma preferible dentro de bloques. Aquí comprueba si el script corre como administrador.

Dónde verlo JORGE.bat, EDWIN.bat, YORMAN.bat

if defined VAR ( echo VAR vale %VAR% ) else ( echo VAR no esta definida ) avanzado

if defined comprueba si la variable EXISTE, aunque esté vacía, sin expandirla: la forma segura de preguntar por una variable que puede no haberse creado nunca.

Dónde verlo no aparece en los scripts; variante de apoyo

if %opcion%==1 ( echo Opcion 1 ) trampa

TRAMPA: sin comillas, si la variable quedó vacía la línea se convierte en «if ==1» y el script muere con error de sintaxis. Pasa siempre que el usuario pulsa Enter en un set /p.

Dónde verlo Correcto: if "%opcion%"=="1" ( ... )

08

Etiquetas y saltos — GOTO

Batch no tiene control de flujo estructurado: tiene etiquetas y saltos. Con eso se construyen los menús, las páginas de ayuda y hasta un while simulado.

6sintaxis
:menu base

Crea una etiqueta: es solo un marcador, no ejecuta nada. El nombre no distingue mayúsculas, así que :menu y :MENU son la misma.

Dónde verlo CAMILO.bat, JORGE.bat

goto menu base

Salta a la etiqueta. También se escribe goto :menu con dos puntos y es equivalente. Es el mecanismo de todos los menús: cada opción termina volviendo a :menu para repintarlo.

Dónde verlo los 20+ scripts del proyecto

goto :EOF avanzado

Sintaxis reservada que significa «fin del script o de la subrutina actual». Es el return genérico: detiene la ejecución sin cerrar la ventana.

Dónde verlo DANIEL.bat, EDWIN.bat, JAIRO.bat

:AYUDA ... :FIN + goto AYUDA avanzado

Patrón de «páginas» del script: cada etiqueta es una pantalla y goto salta entre ellas.

Dónde verlo EjemplosBatch.bat (fragmento repite)

:while1 ... if %x% leq 8 ( ... ) ... goto :while1 avanzado

WHILE simulado: batch no tiene while, se inventa con una etiqueta, un if y un goto que vuelve a la etiqueta. WinSysToolkit lo usa para el monitoreo continuo (timeout /t 3 + goto LOOP_MON).

Dónde verlo EjemplosBatch.bat, WinSysToolkit-ELKIN.bat

:estudio ... :descanso ... (sin goto final) trampa

Si una sección no termina en goto menu o goto fin, la ejecución SIGUE y cae en la etiqueta siguiente, que se ejecuta sin que el usuario la elija.

Dónde verlo angela.bat

! Cierra siempre cada sección con un salto explícito: pause + goto menu, o goto :EOF.

09

Subrutinas — CALL

call convierte una etiqueta en una función reutilizable con parámetros y valor de retorno. Es la diferencia entre un script copiado y pegado y uno mantenible.

8sintaxis
call :suma 5 3 base

Ejecuta la etiqueta :suma del propio archivo pasándole argumentos (dentro son %1 y %2) y regresa a la línea siguiente cuando la subrutina hace goto :EOF o exit /b.

Dónde verlo EjemplosBatch.bat (:suma, :resta)

call :MoverPorTipo "01_Gestion" "docx doc pdf" avanzado

Subrutina con varios parámetros: dentro, %~1 y %~2 los reciben sin comillas. Evita repetir cinco veces el mismo bucle de mover archivos por extensión.

Dónde verlo JAIRO.bat

call :Confirmar "¿Continuar con el analisis?" avanzado

Subrutina reutilizable que pregunta S/N y devuelve el resultado como código: exit /b 0 si acepta y exit /b 1 si no. El llamador hace if errorlevel 1 goto Menu.

Dónde verlo JULIAN.bat

call :REVISAR_SERVICIO "MapsBroker" "Descripcion" "Manual" avanzado

Lo más avanzado: una subrutina recibe servicio, justificación y sugerencia, usa setlocal/endlocal para no ensuciar el entorno y se llama una vez por cada servicio.

Dónde verlo EDWIN.bat

call "%~dp0counter.bat" avanzado

call también lanza OTRO archivo .bat sin cerrar la ventana actual. Sin call, el script externo toma el control y el actual no continúa.

Dónde verlo broma.bat

call npm install -g pnpm avanzado

call envuelve también comandos que en realidad son .bat o .cmd (npm lo es); sin el call, el script actual terminaría ahí.

Dónde verlo YORMAN.bat

@echo off&call:main&goto:EOF avanzado

Todo en una línea con & como separador de comandos: apaga el eco, llama a la subrutina principal y termina. Nota: call:main sin espacio también es válido.

Dónde verlo EjemplosBatch.bat

! El goto:EOF final es obligatorio: sin él, al terminar :main la ejecución «cae» dentro de :suma.

comando1 & comando2 base

El ampersand encadena varias instrucciones en la misma línea; se ejecutan una tras otra sin importar el resultado de la anterior.

Dónde verlo EjemplosBatch.bat, IRAIDA.bat

10

Bucles — FOR

El comando más potente del batch: recorre listas, archivos, carpetas, árboles completos y la salida de otros comandos. Sus opciones /d, /R y /f son las que más se usan en el proyecto.

12sintaxis
for %%x in (1 3 4 6 87) do ( echo Numero: %%x ) base

Recorre una lista literal metiendo varias instrucciones dentro del bloque. En un .bat la variable del bucle lleva DOS porcentajes: con uno solo se expandiría como variable. La letra es libre (i, f, A, E...).

Dónde verlo EjemplosBatch.bat

for %%f in (*.txt) do ( echo Procesando %%f type "%%f" >> "salida.txt" ) base

Red: comandos de los talleres

Los comandos de auditoría y configuración de red que aparecen en el Taller No 4 y se combinan con los .bat de diagnóstico.

12sintaxis
netstat -a · -o · -ano · -b base

Todas las conexiones y puertos con su estado; -o añade el PID dueño, -n evita resolver nombres (más rápido y fácil de filtrar) y -b muestra el ejecutable asociado, lo que exige permisos de administrador.

Dónde verlo JORGE.bat, DANIEL.bat, WinSysToolkit-ELKIN.bat

nslookup www.google.com base

Consulta el DNS y devuelve la IP del dominio. Un mismo dominio puede devolver IPs distintas porque hay varios servidores.

Dónde verlo taller redes

nslookup -type=mx www.ufps.edu.co · -type=ptr avanzado

Consulta los registros MX (servidores de correo del dominio) y los PTR (resolución inversa hostname ↔ IP).

Dónde verlo taller redes

arp -a · arp -a -v · arp -s IP MAC avanzado

Muestra la tabla ARP (qué IP local corresponde a qué MAC, con tipo DINÁMICO o ESTÁTICO) y permite fijar una entrada manual.

Dónde verlo taller redes

net view · net view \\NOMBREPC /ALL base

Lista los equipos visibles en la red local y los recursos compartidos de uno concreto. Falla con error 6118 cuando el descubrimiento está bloqueado o la red es PÚBLICA.

Dónde verlo taller redes

tracert www.google.com · pathping www.google.com base

tracert muestra cada salto (hop) de la ruta con su IP y tiempo; pathping combina ping y tracert y además mide la pérdida de paquetes por nodo (más lento).

Dónde verlo taller redes

netsh interface show interface base

Estado de todas las interfaces de red: nombre, si está conectada y su modo. netsh sin argumentos entra a su propio entorno interactivo (netsh>).

Dónde verlo JORGE.bat, WinSysToolkit-ELKIN.bat

netsh interface ipv4 set address "Ethernet" source=static address=192.168.1.6 mask=255.255.255.0 gateway=192.168.1.1 avanzado

Configura IP estática. Respeta los espacios antes de los signos =: netsh los exige. Para volver a DHCP se usa el mismo comando terminando en «dhcp».

Dónde verlo JORGE.bat, EjemplosBatch.bat

netsh interface ipv4 set dnsservers "Ethernet" static address=8.8.8.8 primary avanzado

Fija el DNS primario; con add dnsservers ... index=2 se agrega uno secundario y con «dhcp» vuelve a automático.

Dónde verlo taller redes

netsh advfirewall firewall add rule name="Puerto TCP 443" dir=in action=allow protocol=TCP localport=443 avanzado

Crea una regla de firewall para abrir un puerto: action=allow para abrir, dir=in entrada (dir=out salida). Con action=block se cierra y con delete rule name=... se elimina.

Dónde verlo taller redes, ROYNER.bat

! Si creas otra regla con el mismo nombre, Windows añade una nueva en vez de reemplazarla: borra la anterior primero.

netsh wlan show wlanreport avanzado

Genera un informe del WiFi en HTML, XML y CAB: consulta NCSI (conectividad), NDIS (controlador), EAP (autenticación) y WCM (gestión de conexiones).

Dónde verlo taller redes

nmap -sVC -O 192.168.20.72 peligro

Herramienta externa de escaneo: -sV detecta servicios y versiones, -sC ejecuta scripts básicos y -O identifica el sistema operativo. Se usa para verificar que las reglas de firewall funcionan.
